Auto mode

  • Server-side classifier by default, free on plans (CLAUDE_CODE_AUTO_MODE_SERVER)
  • Blocks git reset --hard, terraform destroy, cloud metadata access…
  • Asks before the first read outside working directories
  • autoMode.environment, hard_deny, classifyAllShell
  • Denial reason named (e.g. [Data Exfiltration])

Bash sandbox

  • macOS, Linux, WSL2 (not native Windows). Covers Bash, PowerShell, Monitor
  • sandbox.network.strictAllowlist, allowedDomains, tlsTerminate
  • sandbox.credentials: secret masking (mode: "mask", SigV4)
  • sandbox.filesystem.disabled: network only
